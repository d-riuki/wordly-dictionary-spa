
# Wordly — Personal Dictionary

Wordly is a responsive single-page dictionary application built using HTML, CSS, and JavaScript.

It allows users to search for English words, explore their meanings, listen to pronunciations, and save their favourite words.

## Features

- Search for English words
- Display definitions and phonetic spellings
- View examples and synonyms when available
- Listen to word pronunciations
- Save and remove favourite words
- Store saved words using localStorage
- Switch between light and dark mode
- Remember the selected theme
- Responsive design for mobile and desktop
- Handle invalid searches and API errors

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- DOM Manipulation
- Browser localStorage

## API

Dictionary data is provided by the Free Dictionary API.

## Getting Started

1. Clone the repository:

   git clone https://github.com/d-riuki/wordly-dictionary-spa.git

2. Open the project folder in VS Code.

3. Launch index.html using Live Server.

4. Enter an English word to search.

## How to Use

1. Enter a word in the search field.
2. Click Search to retrieve its meaning.
3. Explore definitions, examples, and synonyms.
4. Play pronunciation audio when available.
5. Save favourite words for later.
6. Click a saved word to search for it again.
7. Switch between light and dark mode.
